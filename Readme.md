#  Real Estate CRM

A full-stack Real Estate CRM application to manage leads efficiently.

---

##  Features

- Add new leads  
- View all leads  
- Update lead status (New, Contacted, Qualified, Closed)  
- Delete leads  
- Search leads by name or phone  
- Login system (basic authentication)  
- Clean and responsive UI  

---

##  Tech Stack

### Frontend
- React.js  
- Axios  
- CSS  

### Backend
- Node.js  
- Express.js  
- MongoDB (Local)
